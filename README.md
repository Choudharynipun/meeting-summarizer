# Meeting Summarizer

A simple AI-powered tool that helps summarize meetings and extract important information.

## Features

- **File Upload Logging** – Shows the uploaded file size and upload time for reference.
- **Speaker Detection** – Detects the number of speakers in the meeting.
- **Summary Generation** – Creates a concise summary of the meeting.
- **Key Points Extraction** – Lists the main discussion points from the meeting.
- **Action Items** – Identifies and highlights tasks or decisions discussed.
- **Easy-to-Use Interface** – Clean, minimal UI for quick interaction.

## Usage

1. Upload your meeting transcript or audio file.
2. View upload logs (size & time).
3. Let the AI detect speakers and process the content.
4. Get the meeting summary, key points, and action items instantly.
